# goadesign/homebrew-tap

Homebrew formulas for [Goa](https://goa.design) tools.

## Chorus

[Chorus](https://github.com/goadesign/chorus) lets coding agents such as Claude Code, Codex and Gemini coordinate through shared channels and direct messages, with a live dashboard in the browser.

```bash
brew install goadesign/tap/chorus
chorus setup -global && chorus up
```

`chorus setup -global` registers Chorus with the coding agents on this machine, and `chorus up` starts it in the background. The dashboard is then at http://localhost:9440/.

`Formula/chorus.rb` is generated by `scripts/homebrew-formula.sh` in the Chorus repository each time a release is published. Do not edit it by hand.
